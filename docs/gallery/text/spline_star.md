# Spline Star

*Category*: geometry

Alternating inner and outer vertices form a rounded five-point star.

Ported from the old Gum gallery.

The coordinate system belongs to Graph rather than the spline. `tension` controls Catmull–Rom tangents, replacing the old numeric `curve` prop. Polar helpers now return point objects, which Spline accepts directly.

See [Spline](../../elements/text/Spline.md) and [the runnable source](../code/spline_star.jsx).
