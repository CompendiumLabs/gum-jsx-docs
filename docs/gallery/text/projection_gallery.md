# Projection gallery

The four **GeoMap** panels share one `world_countries()` source and the same
viewport dimensions. Only `projection` changes, making the different shapes and
distributions of area easy to compare. Each map fits the sphere within its panel
using `map-padding`.

The card list generates each panel with its title and projection name. Country
fills and borders use the same shared palette in every panel.

For a clipped globe view, see [projected city markers](globe_markers.md).
For fitting to a subset of countries, see [selected-region fit](selected_region.md).
