# Manual Plot

*Category*: plotting

A sine plot assembled from a Graph, Mesh2D, HAxis, and VAxis, rather than the higher-level Plot component.

Ported from the old Gum gallery.

The graph supplies data mapping. Each axis and mesh declares its tick domain; outside padding reserves space for their labels. Axis placement uses `side` instead of old position and size hacks.

See [Graph](../../elements/text/Graph.md) and [the runnable source](../code/plot_manual.jsx).
