# Atomic Orbitals

*Category*: plotting

Six stylized angular profiles show s, p, and d lobes with separate positive and negative phases.

Ported from the old Gum gallery.

These are schematic 2D angular profiles, not probability-density plots or full 3D orbital surfaces. The diagonal pz profile follows the original projection convention. The py phase intervals now meet at its actual angular zero crossings. Explicit rows preserve the original 1 / 3 / 2 arrangement.

See [SymPoly](../../elements/text/SymPoly.md) and [the runnable source](../code/atomic_orbitals.jsx).
