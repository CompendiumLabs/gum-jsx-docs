# Metal Grid

*Category*: geometry

A luminous 9-by-16 tile matrix sits under a bright layered spline, inside nested dark frames.

Ported from the old Gum gallery.

The old Grid is expressed as positioned cells in a Group. Gaps, tile radii, and layered stroke widths are explicit; the two spline passes approximate a glow without filters.
