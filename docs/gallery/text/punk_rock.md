# Punk Rock

*Category*: text

Three colored text frames form a tilted badge with rounded outer corners.

Ported from the old Gum gallery.

Rotate wraps the completed row. Text keeps its font size; padding and gaps are pixel lengths, and per-side radii round only the exposed ends.

See [Rotate](../../elements/text/Rotate.md) and [the runnable source](../code/punk_rock.jsx).
