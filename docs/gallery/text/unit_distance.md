# Unit Distance

*Category*: networks

A finite set of coefficient vectors in Q(i, ζ₃) produces a dense unit-distance graph. Exact coefficient tests select edges before positions are projected to the plane.

Ported from the old Gum gallery.

The original combinatorial construction is preserved. Segments batches the edge pairs, Points batches markers, and the caption reports vertex and edge counts. Complex arithmetic still returns tuples; ordinary polar/vector helpers return point objects.

See [Segments](../../elements/text/Segments.md) and [the runnable source](../code/unit_distance.jsx).
