# UI Mockup

*Category*: layout

Overlapping desktop-style windows combine a live plot, a fine background grid, and wrapped message text.

Ported from the old Gum gallery.

Window is a reusable single-content Frame containing a vertical stack. Positioned windows have explicit widths; their text determines natural height. Source order controls the overlapping layers.

See [Frame](../../elements/text/Frame.md) and [the runnable source](../code/ui_mockup.jsx).
