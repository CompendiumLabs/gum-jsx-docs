# Atomic Orbitals

*Category*: plotting

Six stylized angular profiles show s, p, and d lobes with separate positive and negative phases.

These are schematic 2D angular profiles, not probability-density plots or full 3D orbital surfaces. The pz profile is shown diagonally, and the py phase intervals meet at its angular zero crossings. Explicit rows give a 1 / 3 / 2 arrangement.
