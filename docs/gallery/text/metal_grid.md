# Metal Grid

A luminous 9-by-16 tile matrix sits under a bright layered spline, inside nested dark frames.

We use [Grid](../../elements/text/Grid.md) to arrange variously colored squares. [Overlay](../../elements/text/Overlay.md) ensures that the **Grid** element determines the natural size of the figure, while the **Splines** match that. Gaps, tile radii, and layered stroke widths are explicit; the two spline passes approximate a glow without filters.

See [Group](../../elements/text/Group.md).
