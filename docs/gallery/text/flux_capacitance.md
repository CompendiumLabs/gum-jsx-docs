# Flux Capacitance

*Category*: plotting

A translucent band fills the space between sine and cosine over a full period. The title is playful; the curves are a plotting demonstration.

Ported from the old Gum gallery.

SymFill uses `upper` and `lower` rather than the old `fy1` and `fy2`. All three sampled marks declare the same domain explicitly.

See [SymFill](../../elements/text/SymFill.md) and [the runnable source](../code/flux_capacitance.jsx).
